# Bリーグ ストーム（v1.8）

B.PREMIER 2026-27 シーズンの実在選手で、自分のチームをそだてて対戦するバスケゲームの Web アプリ（PWA）です。
推しチームとして B.ONE の横浜エクセレンスも入っています。**個人・家族で楽しむためのファンアプリ**です（URL を広く公開しないでください）。

## できること

| 機能 | 内容 |
|---|---|
| 推しチーム | 最初に B.PREMIER 26クラブ＋横浜EX から1つえらぶと、そのロスター全員が自分の選手になる |
| 試合（3D） | 3Dのアリーナで、顔写真を貼った3Dの選手が走る・ドリブル・ジャンプシュートする。選手の大きさは公式の身長・体重どおり。体は筋肉の形のある腕・脚とV字の上半身（ノースリーブ・ひざまでの短パン・ソックス・バッシュ）、顔は元の写真から切りぬいた高画質な画像を、ゆがまないように正面から貼り、鼻・まゆ・ほお・くちびる・あごを少し立体にしている（目・しわ・ひげは写真そのもの）。写真から、ユニフォームの色・髪のボリューム・長い髪（ドレッドなど）・坊主を読み取って選手ごとに変える。バッシュの色も選手ごとにちがう。背番号は胸・背中と頭の上のバッジに表示。5対5フルコート、24秒ルールあり |
| ファウル | ファウルされるとフリースロー（自分の選手はゲージで打つ。CPUは自動）。2本目（最後）が外れたらリバウンドから再開。シュート中のファウルは2本（3Pは3本、決まったら1本）、それ以外のファウルはチームファウル5つ目から1本（得点ボードの F がチームファウル。F4から赤）、4つ目まではいったん試合を止めてサイドラインからスローイン（アウト・24秒も同じ。スローインのパスはカットされず、受けた直後はスティールされない。5秒で自動で入れる） |

| 中断・再開 | 試合は数秒ごとに自動で保存。一時停止→「中断して、あとで再開」か、アプリを閉じても、ホームの「再開する」でスコア・時間・個人成績のつづきから（選手の位置はティップオフからやりなおし） |
| あそびかた | ホームの「あそびかた」と、試合中の一時停止→「操作説明」で操作の説明が見られる |
| 観客と音 | 客席は観客でいっぱい（まるい頭・髪・Tシャツ・腕のある人。肌・髪・服はいろいろで、4割はホームのチームカラー）。点が入ると立ち上がって手を上げる。ゲーム風のBGM（ループ）、観客のざわめき、決まった・スティール・ブロックで「わぁーっ」という歓声、ため息、相手の攻撃中のディフェンスコール（太鼓と手拍子）、ドリブル・ネット・リング・笛・ブザー・バッシュの音（音声ファイルなし、ブラウザで合成）。せっていで効果音・BGM それぞれあり／なし |

| シーズン | 他の26チームと1試合ずつ（全26戦）。ほかのチームどうしの試合も自動で進み、順位表ができる |
| フリー対戦 | 好きなチームと対戦（順位表には入らない） |

## 選手データ

- `tools/fetch_data.py` が B.LEAGUE 公式サイトから取得して `data/players.js` を作ります。
  - ロスター：`/roster/`（在籍中、2026-27）
  - 個人スタッツ：`/stats/`（B.PREMIER と B.ONE の1試合平均）
  - 身長・体重：`/roster_detail/`（`tools/profile_cache.json` に保存、2回目からはとばす）
- 顔写真は公式の画像を 200×250 に縮小して `photos/` に保存しています（3Dの顔に貼るため。約4MB）。写真がない選手は背番号を表示します。
- チームカラーは各クラブのロゴから自動で取っています。
- 能力値はスタッツから計算した、このアプリ独自のものです。出場時間や試合数が少ない選手はポジションの標準値に近づけています。
- シーズンが進んだらデータを取り直してください（育成で上げた分は消えません）。

```bash
python tools/fetch_data.py
```

## パソコンで動かしてみる

```bash
python -m http.server 8766
```

ブラウザで http://localhost:8766 を開きます（`index.html` を直接開くと3Dが動きません）。スマホは横向きがおすすめです。iPad / iPhone で使う方法はバスケ道場と同じです（GitHub Pages ＋ ホーム画面に追加）。

### オフラインで遊ぶ

https のページ（GitHub Pages など）で一度開くと、プログラムと選手の写真・顔・ロゴ（737枚・約10MB）がスマホに自動で保存され、そのあとはネットなしで遊べます。保存の進み具合は「せってい」→「オフライン」で見られます。

- 写真などはアプリを更新しても取り直しません（`sw.js` の `ASSETS` を上げたときだけ取り直します）。
- 文字のフォント（Google Fonts）は、一度表示したものが保存されます。保存前にオフラインになると、スマホの文字で表示されます。
- 同じWi-FiのPCから http で開いた場合は、ブラウザのきまりでオフライン保存は使えません。

## v1.5 の追加

- **横浜エクセレンスのホームユニフォーム**：緑の本体、わきに黒いパネル（緑の六角形もよう）、黒いえり・そでぐり、白い番号、むねのエンブレム。短パンも同じデザインです（スポンサーのロゴは入れていません）。デザインは `js/match3d.js` の `KITS` にあります。
- **外部AIの3Dモデル**：`models/<選手ID>.glb` を置くと、その選手は外部AI（Meshy など）で作ったモデルになります。骨（もも・ひざ・肩・ひじ）を、いつもの動きに合わせて動かします。ファイルがない・読めないときは、いつものモデルのままです。使う選手は `STYLES` の `model` で決めます（今はトレイ・ボイド選手 `models/43445_v3.glb`：TRELLIS.2 で作った `43445_v2.glb`（約33万三角形・11.9MB）を、gltf-transform で約4.3万三角形・2.0MB に軽くしたもの。`models/43445.glb` はドリブル中の写真から作った1つめのモデルで、今は使っていません）。骨のないモデルには、上げた腕や前後にひらいた脚もふくめて、ゲームが自動で骨を入れます。

### TRELLIS.2 でモデルを作る手順（ログインなし）

骨のないモデルを読みこむと、ゲームが体の割合と形から自動で骨を入れて動かします。

1. [Microsoft TRELLIS.2](https://huggingface.co/spaces/microsoft/TRELLIS.2) を開く（ログインなしだと1日あたりの計算時間が約2分なので、1日1体くらい）。
2. **全身・正面向き・まっすぐ立って腕を体から少しはなした写真**（足先まで写っているもの。背景はシンプルなほうがよい）をアップロードして生成する。ドリブル中など体をかたむけた写真だと、骨がうまく入りません。
3. GLB を書き出すときに面の数を減らす設定があれば、3万〜5万くらいにする（スマホで重くならないように）。
4. ダウンロードした GLB の名前を `43445.glb` にかえて、`models/` に入れる。
5. うしろ向き・左右の腕がおかしいなどがあれば、`STYLES` の `modelYaw: Math.PI` などで直します。

### Meshy でモデルを作る手順

1. [Meshy](https://www.meshy.ai/) にログインする（無料プランで作ったモデルは公開あつかいになります。非公開にしたいときは有料プラン）。
2. **Image to 3D** に、全身が正面を向いている写真をアップロードする（腕を体から少しはなした「A」の形がいちばんよい。ドリブル中の写真だと骨がゆがみやすい）。ユニフォームを緑にしたいときは、テクスチャの説明に「green basketball jersey number 1 with black side panels」などと書く。
3. できたら **Remesh** で、三角形 約30,000・テクスチャ 2K にする（スマホで重くならないように）。
4. **Rig（オートリギング）** で人型の骨を入れる。
5. **GLB** でダウンロードして、名前を `43445.glb` にかえて、このフォルダの `models/` に入れる。
6. 試合を開くと、ボイド選手がそのモデルになります。うしろ向きになっていたら、`STYLES` の `modelYaw: Math.PI` を足します。

## v1.6 の追加

- **マスコット「ピック＆ロール」**：横浜エクセレンスの控えに、ピック（#45 PG）とロール（#80 SF）が入りました。データは `data/mascots.js`（`tools/fetch_data.py` で選手データを取り直しても消えません）、写真は `photos/m45.webp`・`photos/m80.webp`（横浜エクセレンスの発表資料の画像から切りぬき）。プロフィールは発表資料より、能力値はプロフィールから決めたこのアプリ独自のものです。
- 3D では、黄緑の大きな頭・丸い耳・黒い目と鼻・白いほっぺ（ロールは前歯、ピックは舌）、緑の手足、こげ茶の手、赤いリストバンドと赤いバッシュのマスコット専用の形になります（`js/match3d.js` の `MASCOT`・`buildMascotHead`）。

### モデルを軽くする手順（gltf-transform）

```
npx @gltf-transform/cli weld 元.glb w.glb
npx @gltf-transform/cli simplify w.glb s.glb --ratio 0.13 --error 0.002
npx @gltf-transform/cli quantize s.glb 軽くしたもの.glb
```

自動の骨入れは、表面に同じ間かくでまいた点で体を測るので、三角形の数を減らしても同じように骨が入ります。肩の関節は左右とも同じ高さ・同じはば（体の中心から身長の ±11.5%、高さ 80%）に置き、首・むね・せなかの内がわは胴体だけ、肩のまわりは胴体から上腕へなめらかに重みをうつすので、腕を上げた形で作ったモデルでも肩がくずれにくくなっています。

## v1.8 の追加：アイテムとガチャ

- **ガチャ**（ホーム →「ガチャ」）：1日3回まで無料（夜0時にもどる）。コインでも引けます（1回 100コイン、10回 900コインで SR以上が1つかくてい）。
  - 出る確率：N 50%／R 30%／SR 15%／SSR 4.5%／UR 0.5%。30回つづけて SSR以上が出なければ、次はかならず SSR以上（無料とコインの回数を合わせて数える）。
  - 同じアイテムがまた出たら強化用にたまる。持ち物でカードを押して ★1〜★5 に強化（★2 に1こ・★3 に2こ・★4 に3こ・★5 に4こ）。★5 に足りたあとはコイン（N 20・R 40・SR 80・SSR 200・UR 500）。
- **アイテム**：バッシュ・ソックス・ヘッドバンド・リストバンド・シューティングスリーブ・ニーパッド・コンプレッションタイツ・テーピング・スポーツゴーグル・マイボールの10種類×10こ＝100種類（`data/items.js`）。
  - 選手の詳細画面でつけます。1人5つまで、同じ種類は1つまで。1つのアイテムは1人だけ（ほかの選手につけると移ります）。
  - 3P・2P・突破・パス・リバウンド・守備は能力値（OVR）に足されます（詳細画面に「🎒+2」のように出ます）。速さ・ゲージのはば・フリースロー・ダンク・スティール・ブロックと、SSR・UR のとくべつな効果（ゾーン、パーフェクトのはば2倍など）は試合の中で効きます。
  - アイテムは自分のチームの選手だけ。CPU のチームはつけません。見た目（3D）は変わりません。
- 持っているアイテムは、ホーム →「アイテム」で種類ごとに見られます。
- **横浜武道館をより本物に**：天井をよこぎる大きなトラスをふやし、大型ビジョンを長いほうの両がわに2面ずつの画面＋鉄のわくにしました。長いほうのかべは灰色のコンクリートと明かりの帯、エンドのかべは木のたて板。客席のあいだは白いスポンサーボード風、床ははちみつ色です。観客は写真のように空席が見える入り（下の段 約6割・上の段 約3〜4割）で、服は半分くらいがチームの緑、あとは黒・白・灰色・紺・茶などの落ちついた色です。
- **トレイ・ボイド選手**：いったん、ほかの選手と同じモデル（写真の顔を貼ったいつものモデル）にもどしました。外部AIのモデル（`models/43445*.glb`）と見た目の特ちょうの設定は、`js/match3d.js` の `STYLES` にコメントとして残してあり、行の先頭の `//` を外せばまた使えます。
